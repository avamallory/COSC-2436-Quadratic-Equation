# Quadratic Equation Root Finder

A short C++ program designed to calculate and display the roots of a quadratic equation using the quadratic formula. This project was developed as part of my **COSC 2436 (Data Structures)** course at HCC.

## 🤖 Features

* **Input Validation:** Safely handles user input for coefficients `a`, `b`, and `c`
* **Precision:** Uses double-precision floating-point values and an epsilon tolerance to account for rounding errors
* Determines whether the equation has two, one, or no real roots
* Uses a `QuadraticEquation` class to manage coefficients and calculations
* Conditional logic and error handling (preventing division by zero when $a = 0$ and handling non-numeric input)
* Use of the standard math library (`<cmath>`) for mathematical operations
* Uses a `QuadraticEquation` class with encapsulated data members
* **Separate Interface and Implementation:** Class declarations are defined in a header file, with method implementations in a separate source file
## 📋 How to Run

### Requirements
* *A C++ compiler that supports C++11 or later*

1. Clone the repository.
2. Open the project in your preferred C++ IDE or navigate to the project directory in a terminal.
3. Build and run the program.
